# Advanced CSS

This project is part of the Holberton School Web Front-End curriculum.

## Description

The project focuses on advanced CSS concepts and styling the Techium website.

## Learning Objectives

- CSS selectors and specificity
- CSS variables and reset
- Box model and layouts
- Pseudo-classes and pseudo-elements
- Gradients, transitions, and animations
- CSS transforms

## Project Structure

- `images/`: Images, logos, and favicon used by the Techium website.
- `README.md`: Project documentation.
